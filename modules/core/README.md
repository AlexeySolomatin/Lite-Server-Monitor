# Системный модуль ядра (Core)

Базовый системный модуль **Lite Server Monitor (LSM)**. Не выполняет мониторинг сам, а устанавливает общесистемные компоненты: юниты ежедневного сводного отчета и общую основу для остальных модулей.

## Назначение

- Установка и обслуживание systemd-юнитов ежедневного отчета:
  - `lsm-report.service` — one-shot служба, собирающая данные со всех активных модулей и отправляющая сводный отчет;
  - `lsm-report.timer` — таймер, запускающий службу по расписанию.
- Служит обязательной зависимостью остальных модулей LSM.

**Важно:** это НЕ мониторинговый модуль. В нем нет `check`-скрипта — это не ошибка и не поломка; такой модуль не проверяется через Module API как мониторинговый.

## Принцип работы

Таймер `lsm-report.timer` ежедневно запускает `lsm-report.service`, который формирует сводный отчет по всем установленным модулям и отправляет его через настроенные каналы уведомлений (Telegram/Email). Если сервер был выключен в момент планового запуска, отчет выпускается сразу после загрузки (`Persistent=true`).

Расписание таймера (см. `files/lsm-report.timer`):

| Параметр | Значение |
|----------|----------|
| Запуск | ежедневно в 08:00 (`OnCalendar=*-*-* 08:00:00`) |
| Догонять пропущенный запуск | да (`Persistent=true`) |
| Случайная задержка | до 5 минут (`RandomizedDelaySec=300`) |

## Файлы модуля

| Путь | Назначение |
|------|-----------|
| `modules/core/files/lsm-report.service` | Служба ежедневного отчета (в репозитории) |
| `modules/core/files/lsm-report.timer` | Таймер ежедневного отчета (в репозитории) |
| `/etc/systemd/system/lsm-report.service` | Служба ежедневного отчета (в системе) |
| `/etc/systemd/system/lsm-report.timer` | Таймер ежедневного отчета (в системе) |

## Ручной запуск

```bash
# Сформировать и отправить отчет немедленно
sudo systemctl start lsm-report.service

# То же через команду LSM
lsm report

# Статус и журнал
systemctl status lsm-report.timer
journalctl -u lsm-report.service -f
```

## Требования

- systemd.
- Установленный LSM (библиотеки `lib/`).

## Установка и удаление

Модуль `core` устанавливается автоматически вместе с LSM как зависимость других модулей и отдельно не отключается.

```bash
# Проверить состояние
lsm modules status core
```
