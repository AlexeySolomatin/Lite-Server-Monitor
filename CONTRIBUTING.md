# Инструкция по коммитам и версионированию LSM

В проекте **Lite Server Monitor (LSM)** настроено автоматическое версионирование на базе стандарта [Conventional Commits](https://www.conventionalcommits.org/). Название каждого коммита определяет, как GitHub Actions обновит версию в файле `VERSION` и создаст новый Git-тег.

---

## 📌 Таблица типов коммитов

| Префикс | Описание | Результат версионирования | Пример |
|---|---|---|---|
| **`fix:`** | Исправление ошибки / багфикс | **PATCH** (`0.1.3` → `0.1.4`) | `fix: исправил падение logging.sh` |
| **`feat:`** | Новая функция или модуль | **MINOR** (`0.1.3` → `0.2.0`) | `feat: добавил модуль мониторинга Docker` |
| **`feat!:`** | Критическое / ломающее изменение | **MAJOR** (`0.1.3` → `1.0.0`) | `feat!: переработка структуры конфигурации` |
| **`docs:`** | Изменения в документации | **PATCH** (`0.1.3` → `0.1.4`) | `docs: обновил справку по установке` |
| **`chore:`** | Служебные правки / рефакторинг | **PATCH** (`0.1.3` → `0.1.4`) | `chore: оптимизировал скрипты сборки` |

---

## 💻 1. Как делать коммиты из консоли (на сервере / локально)

### Однострочный коммит (Основной способ)
```
# Для исправления бага
git add .
git commit -m "fix: исправил ошибку unbound variable в logging.sh"
git push origin main
```

# Для добавления новой фичи
```
git add .
git commit -m "feat: добавил проверку системных служб"
git push origin main
```

---

# Подробный коммит с несколькими строками

Если нужно описать подробности, используйте несколько флагов -m:

```
git commit -m "feat: добавил модуль docker" -m "Подробности: добавлена проверка статуса контейнеров и сбор метрик CPU"
```

---

## 2. Как делать коммиты через веб-интерфейс GitHub

    Откройте нужный файл в браузере на GitHub и нажмите иконку Редактировать (карандаш).
    Внесите изменения в код.
    В правом верхнем углу нажмите синюю кнопку Commit changes....
    В поле Commit message введите заголовок с префиксом (например, fix: поправил опечатку).
    В поле Extended description (необязательно) добавьте подробное описание.
    Нажмите Commit changes.

## ⚙️ Как работает автоматика

    После выполнения git push (или сохранения файла на сайте) автоматически запускается GitHub Actions.
    Скрипт lib/installer/auto-version.sh анализирует историю коммитов.
    Файл VERSION автоматически перезаписывается на новый номер версии.
    В репозитории автоматически создается соответствующий Git-тег (например, v0.1.4).
